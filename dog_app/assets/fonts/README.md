Please add the font file `msyh.ttc` to this directory.
This font is used by `dog_app/common/display_utils.py`.
If `msyh.ttc` is not found, the display utilities will fall back to a default PIL font,
but the visual appearance may differ from the original design.

The original project referenced this font at `/home/jinliang/model/msyh.ttc`.
You may need to obtain this font from the original system or use a suitable alternative
Microsoft YaHei font.
